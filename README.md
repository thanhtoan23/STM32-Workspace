## Hardware & Tools

- Microcontroller: STM32F103C6
- IDE: STM32CubeIDE
- Simulation: Proteus
- Language: C

## Getting Started

```bash
git clone https://github.com/thanhtoan23/STM32-Workspace.git
```

Open the desired lab folder in STM32CubeIDE, build, and flash to the STM32 board or run in Proteus simulation.
