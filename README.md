# STM32 Microcontroller Lab

Lab exercises for STM32F103C6 microcontroller course covering embedded systems fundamentals.

## Lab 1 - GPIO, Delay

**Exercise 1** - GPIO and Delay basics  
**Exercise 2** - Timer configuration and usage  
**Exercise 3** - LCD and Button library  
**Exercise 4** - Finite State Machine (FSM)  
**Exercise 5** - FSM applications (Traffic lights, Turn signals, Password door)  
**Exercise 6** - Real-time clock with DS3231 (I2C communication)  
**Exercise 7** - ADC and PWM

## Lab 2 - Timer

**Exercise 1** - Timer Interrupt  
**Exercise 2** - LED Scanning techniques  
**Exercise 3** - 7-Segment Display  
**Exercise 4** - LED Matrix  
**Exercise 5** - Software Timer  
**Exercise 6-10** - Advanced exercises combining timer, LED, and display control

## Hardware & Tools

- Microcontroller: STM32F103C6
- IDE: STM32CubeIDE
- Simulation: Proteus
- Language: C

## Getting Started

```bash
git clone https://github.com/thanhtoan23/STM32-Workspace.git
```

Open the desired lab folder in STM32CubeIDE, build, and flash to the STM32 board or run in Proteus simulation.
